## 1. What Cybersecurity Actually Is
Protecting systems, networks, and data from unauthorized access, disruption, or damage. Everything downstream (offense, defense, tools) exists to serve the **CIA Triad** — see `Fundamentals/Security-Concepts.md` for the deep dive.

## 2. Offensive Security
- Simulates real attackers to find weaknesses before malicious actors do.
- Core disciplines: **penetration testing** (scoped, permission-based), **red teaming** (broader, stealth-focused, tests detection too), **bug bounty** (public/crowdsourced).
- Mindset: think like an attacker, always ask "what's the next pivot," document everything for the report — the report *is* the deliverable, not just the exploit.

## 3. Defensive Security
- Focused on prevention, detection, and response rather than breaking in.
- Core disciplines: **SOC (Security Operations Center)** analysis, **incident response**, **threat intelligence**, **digital forensics**, **security engineering** (building the defenses offense tries to break).
- Mindset: assume breach, minimize dwell time, reduce attack surface continuously.

## 4. Careers in Cyber (rough map)
| Track | Example Roles |
|---|---|
| Offensive | Penetration Tester, Red Teamer, Bug Bounty Hunter |
| Defensive | SOC Analyst, Incident Responder, Threat Hunter |
| GRC | Compliance Analyst, Risk Analyst, Auditor |
| Engineering | Security Engineer, AppSec Engineer, Cloud Security Engineer |
| Forensics | DFIR Analyst, Malware Analyst |
